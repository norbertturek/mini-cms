# Agent Instructions

This repository is a Nuxt 4 + Strapi 5 mini-CMS.

Before changing code:

- Read `docs/RULES.md`.
- Read `docs/CODING_STANDARDS.md`.
- Check `docs/TASKS.md` and update completed tasks.
- Update `docs/prompts.md` after meaningful work.

Quality gates:

```bash
pnpm format:check
pnpm lint
pnpm test
pnpm build
```

Branching:

- Never push directly to `main`.
- Create a branch from latest `main`.
- Use Conventional Commits.
- Open a PR and wait for explicit user approval before merging.
